Meeting Minutes Assistant — App Map

A local Streamlit proof of concept that turns synthetic in-person meeting transcripts, speaker notes, and a chosen format into editable minutes, then exports the edited text.

Keep the demo synthetic. Generate sends meeting materials to Google Gemini. Never use confidential or real meeting records for this unpaid-tier prototype.

One action through the app

Transcript, speaker notes, and selected format reference are sent to Gemini only when Generate is clicked. Drafts and saved templates stay on this computer.

Reference route through the code

This is a map for finding the implementation; it does not claim the code was toured interactively.

1. Inputs and workflow

app.py — find _restore() and the Generate draft minutes button. This is where the app restores the local draft, checks the inputs, chooses a saved template or typed structure, and connects the visible controls.

2. The AI call

minutes_app/ai_service.py — find generate_minutes(). It makes one structured Gemini request and returns draft text plus unclear-speaker warnings; it does not guess speaker identities.

3. Files the secretary receives

minutes_app/document_export.py — find export_docx() and export_pdf(). The app passes the current edited text to both functions before showing the download buttons.

To change this, start here

  • Colors, control contrast, and footer styling: minutes_app/theme.py — HARBOR_LIGHT and theme_css().
  • What is saved or cleared: app.py — _persist(), _restore(), and _clear_meeting(); then minutes_app/local_store.py.
  • Generation prompt or response fields: minutes_app/ai_service.py — generate_minutes().
  • DOCX/PDF appearance: minutes_app/document_export.py — export_docx() and export_pdf().

A practice to reuse

Turn a requirement into something observable, check it with a test, then try it in the running app. Here, the export tests check that the latest edited line appears in both formats, and the learner confirmed that it did. On another project, use the same pattern: define what a user should see, make a check for it, and verify the behavior yourself.

Run it again

From the project folder, start the virtual environment if needed and run:

.venv/bin/python -m streamlit run app.py

Open the local address printed by Streamlit. Live generation needs a locally configured GEMINI_API_KEY in .env; do not put that file in Git or share its contents. For setup details, see README.md.
